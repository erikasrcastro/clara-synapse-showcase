# Clara by Synapse.ai — Overview

Clara is a lightweight commercial follow-up assistant designed for service providers and MEIs who manage opportunities through WhatsApp.

## Problem

Small businesses often lose sales because follow-ups are forgotten, delayed or spread across informal notes and conversations.

## Pilot scope

Clara helps the business owner:
- register opportunities;
- see overdue and upcoming follow-ups;
- track open pipeline value;
- draft concise follow-up messages with AI assistance;
- use WhatsApp through a governed flow;
- keep customer contact consent visible.

## Architecture at a glance

The pilot uses:
- a responsive web interface;
- secure cloud authentication with MFA;
- cloud persistence;
- a server-side integration layer for AI and WhatsApp;
- a private source repository.

This public repository intentionally contains no application source code.
