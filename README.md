# Clara by Synapse.ai

**Clara** is a lightweight follow-up assistant for service providers and MEIs who manage commercial conversations through WhatsApp.

## What Clara helps with
- keep opportunities from being forgotten;
- see follow-ups due or overdue;
- track open pipeline value;
- prepare concise follow-up messages with AI assistance;
- send through an approved WhatsApp flow with a manual fallback.

## Pilot
This repository is the **public showcase only**.

It intentionally contains:
- product overview;
- synthetic screenshots/demo assets;
- public architecture overview;
- value proposition;
- results and lessons learned.

It intentionally does **not** contain application source code, secrets, customer data, private prompts, internal governance files, or security-sensitive implementation details.
